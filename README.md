# LeadFlow Landing Page

A modern, responsive landing page for a cold email lead generation agency built with React and Tailwind CSS.

## Features

- **Dark gradient design** with glassmorphism effects
- **Fully responsive** mobile-first design
- **Smooth animations** and hover effects
- **Professional B2B SaaS aesthetic**
- **Complete sections**: Header, Hero, Stats, Services, How It Works, Pricing, FAQ, Contact, Footer

## Tech Stack

- React 18 with TypeScript
- Tailwind CSS for styling
- Lucide React for icons
- Responsive design with mobile-first approach

## Getting Started

### Prerequisites

- Node.js (version 16 or higher)
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm start
```

3. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

### Build for Production

```bash
npm run build
```

This builds the app for production to the `build` folder.

## Design Features

- **Header**: Fixed navbar with backdrop blur, logo, navigation, and mobile hamburger menu
- **Hero**: Centered layout with gradient text, CTAs, and social proof
- **Stats Bar**: Key metrics display with large numbers
- **Services**: 3-card grid with icons and hover effects
- **How It Works**: 3-step process with numbered circles
- **Pricing**: 3-tier pricing with featured plan highlighting
- **FAQ**: Expandable question cards
- **Contact**: Form with validation styling
- **Footer**: Links and copyright information

## Customization

The landing page is built with Tailwind CSS utility classes, making it easy to customize:

- Colors: Modify the gradient backgrounds and accent colors
- Typography: Adjust font sizes and weights
- Spacing: Change padding and margins
- Animations: Customize hover effects and transitions
